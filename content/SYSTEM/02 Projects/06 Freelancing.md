Not every Project is a grand undertaking, some are just odd-jobs performed to pay your tab or to purchase some supplies for an upcoming journey. Freelancing represents the work done by bards playing at taverns, handymen nailing some shutters back together, or a quick jaunt performed by an impromptu courier.
## Base Pay by Work Type
You may only take work on of a particular tier if you have a skill of that tier. Likewise, if you have a tool, it must be of use to the task being performed. The DC for Freelancing begins at 5, then the tier of work and tool are added to it. They are always 1 Segment long.

| Tier of Work / Tool | Base Pay | DC  |
| ------------------- | -------- | --- |
| Unskilled work      | 5        | +0  |
| Tier 1 skill work   | 10       | +1  |
| Tier 2 skill work   | 50       | +3  |
| Tier 3 skill work   | 150      | +5  |
| Tier 1 tool         | 5        | -1  |
| Tier 2 tool         | 15       | -2  |
| Tier 3 tool         | 25       | -3  |

| Result       | Payout              |
| ------------ | ------------------- |
| Catastrophic | No pay              |
| Failure      | Half base pay       |
| Success      | Full base pay       |
| Breakthrough | Full base pay + 50% |
